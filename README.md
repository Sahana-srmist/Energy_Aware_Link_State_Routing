# Energy-Aware Link-State Routing for Efficient Network Communication

## Project Overview
This project implements a web-based simulation of energy-aware routing in computer networks. It demonstrates route selection using network parameters such as energy consumption, link cost, and transmission delay.

## Features
- Interactive network topology visualization.
- Source and destination node selection.
- Routing algorithm selection.
- Energy-aware link weight calculation.
- Link failure simulation and alternate route recalculation.
- Display of routing and performance metrics.

## Network Configuration
- Number of routers: 20
- Number of simulated links: 46
