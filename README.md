# Energy-Aware Link-State Routing for Efficient Network Communication

## Project Overview
A browser-based network-routing simulation that demonstrates route selection on a weighted network graph and allows users to explore link-failure scenarios and route recalculation.

## Network Configuration
- Routers/nodes: 20
- Simulated links: 46

## Technologies
- HTML
- CSS
- JavaScript

## Repository Structure
- `Code/` – Website source code (`index.html`; styling and JavaScript are included in this file).
- `Report/` – Project appendix document.
- `Presentation/` – Project presentation.
- `Documentation/` – Supporting project diagram/reference material.

## How to Run
1. Download or clone this repository.
2. Open `Code/index.html` in a modern web browser.
3. Select the source and destination nodes and explore the available simulation controls.
