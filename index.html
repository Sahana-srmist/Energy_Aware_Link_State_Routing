How does link-failure recovery work?

  1. Detect or inject a link failure.
  2. Mark the failed edge unavailable in the graph.
  3. In link-state routing, advertise updated link-state information to routers.
  4. Recompute the shortest-path tree using the selected algorithm.
  5. Install the new route if an alternate path exists.

Proposed energy-aware metric

For each link, normalize energy (E), cost (C) and delay (D) across active links, then calculate:

W = αEₙ + βCₙ + γDₙ

Energy-aware Dijkstra selects the route with the lowest sum of W. The weights α, β and γ express the relative importance of each metric.

Fair interpretation

  • Cost-only Dijkstra and Bellman-Ford should find the same minimum-cost route when tie-breaking is equivalent.
  • BFS is a hop-count baseline and may choose a higher-cost route.
  • The proposed method can trade cost for lower energy or delay.
  • This is a graph simulation, not a real OSPF deployment; convergence and packet delivery are not measured from live traffic.
